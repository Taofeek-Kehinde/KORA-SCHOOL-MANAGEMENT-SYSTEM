# Kora School Management System - Frontend

## Tech Stack
- React 18
- Vite
- Tailwind CSS
- React Router v6
- React Query
- Recharts
- Framer Motion

## Setup
1. Copy `.env.example` to `.env` and fill in values
2. Run `npm install`
3. Run `npm run dev` for development
4. Run `npm run build` for production

## Pages
- Homepage
- Login/Register
- Super Admin Dashboard
- School Admin Dashboard
- School Registration
- Student Management
- Teacher Management
- Billing & Subscriptions
